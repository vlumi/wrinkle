# Java backend, 2026-10-10

The protocol in [measuring.md](../measuring.md). Raw runs: [2026-10-10-java.jsonl](2026-10-10-java.jsonl). Taken in the same session, on the same machine and infrastructure, as the Go run in [2026-10-10-go.md](2026-10-10-go.md); the comparison is in [2026-10-10-go-vs-java.md](2026-10-10-go-vs-java.md).

- Commit: 6f5853d
- Backend: OpenJDK 25.0.4.1, default JVM flags (G1, heap sized by the JVM), one process with roles gateway and fanout, default flags (32 connections per keyspace)
- Machine: MacBook Pro, Apple M4 Max (16 cores), 48 GB, macOS 26.7.1; Docker Desktop 29.8.2 with 16 CPUs and 8 GB
- Infrastructure: `infra/docker-compose.yml` as committed: 16 outbox partitions, Debezium polling every 20 ms
- Resident memory read with `ps`, since the JVM exporter does not report it on macOS

## Idle connections

| Connections | Backend RSS |
|---|---|
| 500 | 246.3 MiB |
| 1000 | 274.2 MiB |
| 2000 | 260.2 MiB |
| 4000 | 300.5 MiB |

Least-squares slope: **13 KiB per connection**, baseline 246 MiB. The points are not monotonic: the JVM sizes its heap by its own rules and the RSS includes uncollected garbage, so the slope from four single runs says little. Repetitions, a fixed heap (`-Xmx`), or the live set after a forced GC would give a real figure.
